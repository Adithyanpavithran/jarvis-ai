# Jarvis chat/session notes

## Current status
- Jarvis is now in a continuous-listening mode.
- Wake word is removed.
- Ollama is connected for conversational replies.
- Whisper-based local speech recognition is enabled.
- Stop handling and media-opening commands are now implemented.

## User goals
- Build a free, local, speaking Jarvis-style assistant.
- Use Ollama for AI responses.
- Keep the assistant interactive and voice-driven.
- Improve media requests so specific songs or topics open more directly.

## Notes
- If microphone quality is poor, recognition may still be inconsistent.
- The assistant is currently best suited for short spoken commands and simple conversational prompts.
- The latest YouTube update improves search-based opening for specific requests.
- Future improvements may include better microphone auto-selection and more natural turn-taking.
